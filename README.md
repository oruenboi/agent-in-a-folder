# Codex Markdown Wiki Starter

A local Codex project with shared rules in `AGENTS.md`, scoped instructions in `wiki/AGENTS.md` and `raw/AGENTS.md`, and a small Markdown wiki backed by source captures.

## Start here

1. Create a repository from this template and open its root as a local Codex project.
2. Set your project name in `AGENTS.md` and your scope in [the project plan](devplan/plan.md).
3. Ask Codex to ingest an approved source or explore the fictional example through the [wiki index](wiki/index.md).

The [setup guide](SETUP.md) explains the folder structure and how to add the same setup to an existing project.

The [optional OKF v0.2 bundle](examples/okf/index.md) shows how to exchange a selected wiki fact with its source. Treat `examples/okf/` as the bundle root and use `wiki/` for routine Codex work. [OKF v0.2 specification](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/SPEC.md)

## Try it

- Ask “From the wiki, when is the sample project’s glossary review? Cite the evidence.” The source records Tuesdays.
- Ask “From the wiki, what budget was approved for the sample project?” Expect an explicit evidence gap. Check that both queries leave the working tree clean.
- Ask “Re-ingest sample-kickoff at revision v1.” Check that the capture and source note are reused.

Record the results in [the setup checklist](devplan/todo.md).
