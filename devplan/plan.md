# Wiki setup plan

Create a reusable folder for AI assistants that can read and edit local files. Use scoped project instructions and one canonical Markdown knowledge bundle in OKF v0.2. Include a fictional source so users can try questions and check citations as soon as they open the folder.

- Route wiki and source-capture work from the root to the relevant nested `AGENTS.md`.
- Keep source captures in `raw/` and package approved references with the bundle when local evidence is needed.
- Verify OKF frontmatter, citations, links, and source integrity. Use a fresh assistant session to check retrieval and repeated ingestion.
